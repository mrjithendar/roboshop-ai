Usage: ./init.sh [--profile dev|docker|minikube|aws] [--check|--dry-run]
Hosts: CentOS Stream 9/10, Amazon Linux 2023, Ubuntu 22.04/24.04 LTS,
macOS with existing Python 3.9+; x86_64/ARM64 only.
Default: dev. --check reports only; --dry-run prints decisions without changes.
Profiles:
  dev       Git, curl, jq, managed Python, Node/npm; isolated .venv (no app packages).
  docker    Base tools + Docker Engine/client; macOS requires an existing engine.
  minikube  docker + kubectl, Helm, Minikube, OpenSSL; no cluster creation.
  aws       Base tools + AWS CLI v2, Terraform; macOS requires existing AWS CLI v2.
Compatible tools are reused; incompatible tools are never silently replaced.
Downloads retain SHA256/signature checks. No Homebrew or Docker Desktop bootstrap.
macOS missing base packages require existing Homebrew. No shell-profile edits.
Linux package/service operations may use sudo; private installs do not.
--check checks tool versions only, not daemon access, application or deployment readiness.
No cloud provisioning, credentials, deployment, migrations, seeds or registration.
Exit: 0 compatible/plan; 1 missing/unsupported/failure; 2 invalid arguments.
See docs/operations/scripts.md for operation-specific restrictions and commands.
