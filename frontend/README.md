# Storefront

The gateway serves `index.html`, `styles.css`, and `app.js` at http://localhost:3000.
Use `npm run dev` from the repository root. Features include category/search/stock
filters, sorting, product details, persistent bag, explicit demo checkout, shopping
assistant, and a live system-status dialog. Product and model text is rendered with
`textContent`, not injected HTML. Native dialogs provide keyboard focus management.
