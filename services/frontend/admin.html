No AWS access keys are collected. Bedrock uses the shopping agent's workload identity. Connection tests make a small model request and may incur provider charges.

Optional Bedrock fallback

Opting in sends your question and retrieved catalogue context to Amazon Bedrock when Ollama has an eligible failure. Bedrock inference and activation tests incur AWS usage charges, which vary by model and tokens. Both attempts may incur processing costs after a timeout. Inference profiles may process data across regions. Review your model/profile locations and data-processing requirements. Authentication uses the workload IAM role; no AWS keys are collected.

Saving an enabled policy tests both providers before activation.

Disconnect disables AI generation for subsequent requests. It does not stop or delete an Ollama EC2 instance. Already-started generations may finish. Queued attempts and fallback must recheck the active configuration.

User access

Customers can shop. Admins manage products. Only the protected super admin manages roles and configuration. Changing access signs that user out.
